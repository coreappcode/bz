# Android sync notes

Last updated: 2026-10-27

## How the Android app gets the web app

`bzead-android` is a Capacitor wrapper with no web source of its own. It packages
the compiled output of `Bzeadstore-main` (`webDir: ../Bzeadstore-main/dist-buyer`).
The buyer build is made with `VITE_APP_MODE=buyer`, which removes seller and admin
routes.

To refresh the Android app after any web change:

```bash
cd Bzeadstore-main && npm install && npm run build:buyer
cd ../bzead-android && npm install && node scripts/prepare-assets.mjs && npx cap copy android
```

Then build the APK/AAB on a machine with the Android SDK (`npm run build:debug` or
`npm run build:release` in `bzead-android`).

## Environment

Build values live in `Bzeadstore-main/.env`, which is gitignored. Never commit it
or put live keys in `.env.example`. Required for the buyer build:
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_STRIPE_PUBLISHABLE_KEY`,
`VITE_ONESIGNAL_APP_ID`.
